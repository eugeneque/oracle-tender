# Транскрибатор с распознаванием говорящих

Переводит видео (или аудио) в текст и помечает, кто что сказал.

## Установка

```bash
./setup.sh
```

Нужны `ffmpeg` (`brew install ffmpeg`) и Python 3.11+. Модели скачиваются
автоматически при первом запуске (~3 ГБ для `large-v3`).

## Запуск

```bash
.venv/bin/python transcribe.py "встреча.mp4" --speakers 3
```

Рядом с исходным файлом появятся три файла:

| Файл    | Что внутри                                            |
|---------|-------------------------------------------------------|
| `.txt`  | диалог: `[00:01:23] Спикер 2: текст реплики`          |
| `.srt`  | субтитры с именами говорящих                          |
| `.json` | таймкоды по каждому слову — для дальнейшей обработки  |

## Полезные ключи

- `--speakers 3` — точное число участников, если известно (заметно повышает
  точность разделения); иначе — `--max-speakers 6`;
- `--names "Иван,Мария,Пётр"` — подставить имена вместо «Спикер 1/2/3»
  (в порядке первого появления в записи);
- `--prompt "ФГИС, тендер, Компас, ИТ-инфраструктура"` — список терминов,
  фамилий и аббревиатур; Whisper начинает писать их правильно;
- `--language auto` — если запись не на русском или двуязычная;
- `--model medium` — втрое быстрее `large-v3`, но заметно менее точно.

## Как это работает

1. `ffmpeg` вытаскивает дорожку 16 кГц моно;
2. **faster-whisper** (`large-v3`) распознаёт речь с таймкодом каждого слова;
   включён VAD-фильтр и отключён `condition_on_previous_text` — вместе они
   убирают типовые «галлюцинации» Whisper на паузах и длинных записях;
3. **диаризация** размечает интервалы речи по говорящим;
4. каждому слову назначается говорящий по наибольшему перекрытию интервалов,
   слова собираются в реплики (новая реплика — при смене голоса или паузе > 2 с).

## Два режима диаризации

**`simple`** (по умолчанию, ничего настраивать не нужно) — голосовые отпечатки
ECAPA + кластеризация. Хорошо работает, когда участники говорят по очереди.

**`pyannote`** (точнее, особенно при перебивках и коротких репликах) — требует
бесплатного токена Hugging Face:

1. принять условия на страницах моделей
   `pyannote/speaker-diarization-3.1` и `pyannote/segmentation-3.0`;
2. создать токен в настройках профиля Hugging Face;
3. запустить:

```bash
export HF_TOKEN=hf_ваш_токен
.venv/bin/python transcribe.py "встреча.mp4" --diarizer pyannote --speakers 3
```

## Если говорящие путаются

- укажите `--speakers N` — это самый действенный ключ;
- если вы не задавали `--speakers`, а программа решила, что говорящий один, снизьте
  `--split-threshold` (например, `0.15`): это минимальная чёткость разделения
  голосов, ниже которой запись считается монологом;
- перейдите на `--diarizer pyannote` — он заметно лучше на перебивках.

Разделение опирается на `linkage="ward"`, а не на напрашивающийся
`average` + косинусное расстояние: последний на длинных записях отделяет
один шумный фрагмент вместо реальной границы между голосами (на 16-минутной
встрече давал разбиение 774 окна против 1). Одиночные выбросы дополнительно
сглаживаются по соседним окнам.
