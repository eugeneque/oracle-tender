# Sova Scanner (Тендеры)

Рабочий репозиторий проекта по автоматизации работы с тендерами.

## Структура

| Каталог | Что это |
|---|---|
| `oracle-t/` | Основное приложение: FastAPI-бэкенд (`backend/`) и React+Vite фронтенд (`frontend/`). Подробности — в [oracle-t/README.md](oracle-t/README.md) и [oracle-t/ARCHITECTURE.md](oracle-t/ARCHITECTURE.md) |
| `Sova Scanner.html` | Статический прототип интерфейса |
| `install.sh` | Установщик: ставит систему целиком на сервер или рабочую машину |
| `DEPLOY.md` | Инструкция для DevOps: развёртывание, обновление, бэкапы, диагностика |

## Установка

Всё ставится одним скриптом — он сам поднимает системные пакеты, PostgreSQL, Python-окружение,
собирает интерфейс и, в серверном режиме, заводит службы:

```bash
git clone <адрес репозитория> tender
cd tender
./install.sh
```

Установщик спросит режим:

| Режим | Что делает | Где применять |
|---|---|---|
| `server` | systemd + nginx, автозапуск при перезагрузке, интерфейс на 80 порту | боевой сервер (Linux) |
| `docker` | вся система в контейнерах (`docker compose`) | сервер, где не хочется ставить пакеты в хост |
| `local` | только зависимости и сборка, запуск через `oracle-t/run.sh` | рабочая машина разработчика |

Без вопросов: `sudo ./install.sh --mode server -y`. Посмотреть план, ничего не меняя:
`./install.sh --dry-run`. Полный список ключей — `./install.sh --help`.

Логин и пароль администратора генерируются при установке и печатаются в конце — они же лежат
в `oracle-t/.env`. Ключ Yandex AI Studio, SMTP-ящик и учётные данные площадок задаются потом
в интерфейсе, в разделе «Настройки».

Тот же скрипт работает и как обновление: `git pull && ./install.sh --mode server -y` —
повторный запуск переиспользует созданные venv, базу и `.env`.

Развёртывание на боевом сервере, HTTPS, резервное копирование и диагностика — в
[DEPLOY.md](DEPLOY.md).

## Запуск

Конфигурация окружения — `oracle-t/.env` (шаблон: [oracle-t/.env.example](oracle-t/.env.example)).
Скрипт запуска локального стенда — `oracle-t/run.sh`.

## Что не хранится в репозитории

Секреты (`.env`, `.credentials_key`), виртуальные окружения, `node_modules`,
логи и каталог загруженных документов `backend/storage/`.
