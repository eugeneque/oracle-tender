## Общие правила для промптов — как соблюдаются

| Правило | Статус |
|---|---|
| Цитата и документ у факта | Есть у условий поставки и договора, требований, квалификации, итогов, цены/НДС; у выводов-оценок — основание и неопределённость |
| «Не указано» ≠ «нет условия» | Подтверждённое отсутствие — только с цитатой; недоступный документ и отсутствие сведений различаются |
| Противоречия — оба значения с источниками | Протоколы, редакции документов, цена/НДС (`conflicts`); автоматический расчёт при конфликте запрещён |
| Часовой пояс | Пакет ИИ — по Москве, события — в UTC, момент из карточки ЕИС — с поясом заказчика; неизвестный пояс не угадывается |
| Суммы и количества не заменять нулём | Пустые значения не передаются; НДС считается только по исходной сумме |
| Было/стало, без выдуманных изменений | Слепки мониторинга, постоянные `event_id`, первая загрузка не порождает изменений |
| Лот не смешивать с процедурой | `SINGLE` / `PROCEDURE` / `LOT`; позиции, требования, документы, условия, итоги и НДС относятся к лоту только по явной связи |
| Повтор и защита от дублей — у обработчика | `request_id`, `analysis_id`, `event_id`, `supersedes_event_id`, постоянные ключи строк |
